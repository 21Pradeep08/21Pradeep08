## 🔬 Research: AI-driven continuous network slicing for healthcare

> Hospitals share one 5G network between life-critical traffic (ICU, emergency) and routine traffic (monitoring, records). Static allocation either wastes bandwidth or lets critical traffic suffer. I study how a learned policy can allocate bandwidth continuously, in real time.

- **Baseline:** Q-Learning / DQN slicing on the DeepSlice dataset, **93.2% QoS satisfaction** on **63K+ real-world slice requests**
- **Extension:** **DDPG + LSTM** with traffic-aware reward shaping for continuous bandwidth control across ICU, emergency and ECG slices
- **Method:** continuous severity-based criticality model, SLA-penalty reward design, per-patient prioritised experience replay, compared against Equal Sharing, Round Robin, Static Priority and heuristic baselines
- **Supervisor:** Dr. Moirangthem Biken Singh, NIT Silchar
